## Built with

`HTML5` · `CSS3` · `Vanilla JavaScript` · `WebP` · `Netlify`

A deliberately lightweight **static website**: no framework, no database, no backend server, and no build pipeline required.

The layout adapts to phones, tablets, laptops, and large monitors. It includes a responsive navigation menu, interactive gallery, animation with reduced-motion support, and keyboard-friendly interactions.

## Run locally

Clone or download this repository, then from the folder containing `index.html` run:

```bash
python3 -m http.server 8000
```

Open **http://localhost:8000** in your browser. No `npm install` or build command is needed.

## Deploy

The site is hosted on **Netlify**:

**[marvelous-fenglisu-f4438f.netlify.app](https://marvelous-fenglisu-f4438f.netlify.app/)**

To deploy your own version:

1. Fork or clone the repository.
2. Import the repository in Netlify, or drag the folder containing `index.html` into [Netlify Drop](https://app.netlify.com/drop).
3. Keep the publish directory as `.` (repository root). The included `netlify.toml` already specifies this.
4. If connected through Git, subsequent pushes to the production branch can trigger new deployments.
